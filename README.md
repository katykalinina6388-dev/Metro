# Поездной диспетчер — Невско-Василеостровская линия

Двухмерная игра-симулятор: вы — поездной диспетчер 3-й линии Петербургского метрополитена
(Беговая — Рыбацкое). Режим «песочница», интерфейс, распознавание команд и голоса машинистов — на русском.

Готовая сборка для Windows — один исполняемый файл без установки и без загрузки чего-либо из сети:
`dist/Dispetcher-metro-NVL.zip` → «Диспетчер метро.exe» (см. `docs/ПРОЧТИ.txt`).

## Что смоделировано

- **Карта** — вид сверху в реальной географии: оба главных пути по данным OpenStreetMap (кривые и взаимное
  положение тоннелей, двухпутный тоннель Приморская — Беговая), Нева и залив, контур города и районов.
  Масштаб плавный: от всей линии до отдельного вагона.
- **Путевое развитие**: перекрёстные съезды и оборотные тупики на «Беговой» и «Рыбацком», пошёрстные съезды у
  «Приморской», «Василеостровской», «Обухово», тупики у «Маяковской», «Пл. Александра Невского» (два пути),
  «Ломоносовской», соединительный путь и веер путей депо «Невское».
- **Поезда** — шестивагонные составы, каждый вагон рисуется отдельно. Заполнение показано людьми:
  сначала заняты сидячие места вдоль бортов, затем вагон заполняется по всей площади. Тяга, торможение,
  уклоны (по глубине станций) учитываются в движении.
- **Безопасность движения**: блок-участки, замыкание маршрутов, АЛС-АРС. Стрелки — автоматика или ручной
  перевод. Столкновение и сход возможны только при грубой ошибке (проезд запрещающего сигнала по приказу,
  аварийный перевод стрелки).
- **Пассажиропоток** по времени суток: утренний и вечерний часы пик, межпик, ночь; матрица корреспонденций
  между станциями. Поезда выпускаются из депо и тупиков и убираются обратно.
- **Время**: реальное (1 с = 1 с) или ускоренное (1 игровая минута = 5 секунд), выбор времени начала смены.
- **Нештатные ситуации** с настраиваемой частотой: неисправность состава, двери, человек на пути,
  бесхозный предмет, отказ стрелки или светофора, ограничение скорости, снятие напряжения.
- **Голос**: приказы машинистам голосом (встроенное офлайн-распознавание Vosk или системное Web Speech —
  переключатель в меню), текстом или кнопками; машинисты отвечают голосом.

## Устройство

| Путь | Что там |
|---|---|
| `main.go`, `open_*.go` | запускающая программа: встроенные файлы игры + локальный сервер + окно браузера в режиме приложения |
| `game/` | сама игра (HTML5 Canvas, без сторонних библиотек, кроме распознавателя речи) |
| `game/js/track.js` | построение графа путей из геометрии и описания путевого развития (`game/js/line.js`) |
| `game/js/sim.js` | модель: движение, замыкание маршрутов, пассажиры, приказы, аварии |
| `game/js/incidents.js`, `commands.js`, `phrases.js` | нештатные ситуации, разбор команд, тексты радиообмена |
| `game/js/render.js`, `ui.js`, `radio.js`, `mic.js` | карта, интерфейс, озвучка, микрофон |
| `tools/geo/` | получение и упрощение данных OpenStreetMap → `game/data/geo.js` |
| `tools/voice/`, `tools/vosk/` | генерация озвучки (Piper) и упаковка модели распознавания |
| `tools/test/` | проверки без интерфейса и в браузере |

## Сборка

Нужен только Go 1.22+ (все файлы игры уже лежат в `game/`):

```sh
tools/build.sh        # dist/Dispetcher-metro-NVL.zip и dist/metro-dispatcher-linux
```

Для разработки: `go run . -dev game` — раздаёт файлы прямо из каталога `game/`.

## Проверки

```sh
node tools/test/graph.js            # целостность графа путей
node tools/test/run.js 5 26 3       # 26 часов работы линии с частыми ЧП (старт в 05:00), без аварий и заторов
node tools/test/run.js 7 12 2 manual  # ручное управление стрелками со «сценарным игроком»
node tools/test/cmd.js              # разбор и исполнение команд
node tools/test/crash.js            # столкновение и сход — только при грубой ошибке
node tools/test/shots.js <url> <каталог>          # снимки экрана (Playwright)
node tools/test/voice.js <url> <wav> 12 depot     # голосовая команда через встроенное распознавание
```

Лицензии сторонних компонентов и данных — в `THIRD-PARTY.md`.
